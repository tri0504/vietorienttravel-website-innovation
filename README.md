# Viet Orient Travel

Foundation for the Viet Orient Travel website.

## Development

```bash
npm install
npm run dev
```

## Structure

- `src/components`: reusable UI and shared layout components
- `src/data`: structured, CMS-ready business content
- `src/pages`: route-level page composition
- `src/styles`: Sass tokens, base rules, components, utilities, and entrypoint
- `src/App.jsx`: route registry and layout boundary
